# Типы связей в Knowledge Graph

**Обновлено:** июль 2026

## Обзор

Типы связей определяют характер отношений между заметками в графе знаний. Правильный выбор типа помогает структурировать знания, улучшает навигацию и делает граф визуально осмысленным.

| Тип | Иконка | Вес по умолчанию | Стиль линии | Цвет |
|------|--------|------------------|-------------|------|
| Ссылка | 📖 | 0,8 | сплошная | `#3366ff` |
| Зависимость | 🔗 | 0,7 | пунктир `[10, 3]` | `#ff6600` |
| Связано | 🔀 | 0,5 | сплошная, при весе < 0,3 → пунктир `[6, 4]` | `#999999` |
| Своя | ✨ | 0,5 | пунктир `[2, 6]` | `#ff66ff` |
| Родитель | ⬆️ | 0,9 | сплошная | `#2dd4bf` |
| Дочерняя | ⬇️ | 0,9 | сплошная | `#f472b6` |

## Доступные типы

### Ссылка

- **Иконка:** 📖
- **Смысл:** Одна заметка просто упоминает другую.
- **Когда использовать:** Перекрёстные ссылки, цитаты, «см. также».
- **Пример:** «Квантовая физика» → Ссылка → «Принцип неопределённости».
- **Визуал:** Синяя сплошная линия.

### Зависимость

- **Иконка:** 🔗
- **Смысл:** Целевая заметка не работает или не понимается без исходной.
- **Когда использовать:** Предусловия, упорядоченные шаги, учебные траектории.
- **Пример:** «Docker Compose» → Зависимость → «Docker Basics».
- **Визуал:** Оранжевая пунктирная линия.

### Связано

- **Иконка:** 🔀
- **Смысл:** Заметки тематически связаны, но ни одна не зависит от другой.
- **Когда использовать:** Близкие темы, альтернативные подходы, связанные концепции.
- **Пример:** «JavaScript» → Связано → «TypeScript».
- **Визуал:** Серая сплошная линия; становится пунктирной, если вес ниже 0,3.

### Своя

- **Иконка:** ✨
- **Смысл:** Пользовательский тип для отношений, не покрытых стандартным набором.
- **Когда использовать:** Специфичные для проекта отношения, экспериментальные категории.
- **Пример:** «Продолжение», «Противоречит», «Вдохновлено».
- **Визуал:** Пурпурная пунктирная линия.

### Родитель

- **Иконка:** ⬆️
- **Смысл:** Исходная заметка — более широкая тема, в которую входит целевая.
- **Когда использовать:** Иерархии, категории, деревья тем.
- **Пример:** «Программирование» → Родитель → «Функциональное программирование».
- **Визуал:** Бирюзовая сплошная линия.

### Дочерняя

- **Иконка:** ⬇️
- **Смысл:** Исходная заметка — подтема целевой.
- **Когда использовать:** Подтемы, подкатегории, детализация.
- **Пример:** «Функциональное программирование» → Дочерняя → «Программирование».
- **Визуал:** Розовая сплошная линия.

## Выбор типа

```
Является ли одна заметка предусловием для другой?
  Да → Зависимость
  Нет →
    Является ли одна заметка более / менее широкой темой?
      Да → Родитель / Дочерняя
      Нет →
        Это просто упоминание или источник?
          Да → Ссылка
          Нет →
            Заметки тематически близки?
              Да → Связано
              Нет → Своя
```

## Визуальное кодирование

- **Цвет** берётся из определения типа (`LinkType.color`).
- **Пунктир** берётся из `LinkType.lineDash`. Тип `related` переключается на `[6, 4]`, если `weight < 0,3`.
- **Толщина линии** — `Math.max(1, weight * 4)`, умножается на 1,5 при предупреждении о дублирующейся связи.
- **Непрозрачность** рассчитывается через `LinkType.getColor(weight, fadeOpacity)`, с базовой непрозрачностью `0.4 + weight * 0.4`.
- **Двунаправленные связи** (A→B и B→A) рисуются двумя зеркальными квадратичными кривыми, чтобы не накладываться.
- **Удалённые связи** растворяются, **новые** появляются с fade-in анимацией.

## Интеграция в UI

- `LinkTypeSelector` (`frontend/src/components/molecules/LinkTypeSelector.svelte`) — выбор типа с иконкой, цветом и описанием.
- `CockpitNoteDetails` — список связей заметки с иконкой, весом, `source_type` и `last_weight_update`.
- `LinkTooltip` — тултип на графе с типом, цветом, весом, источником/целью и датой обновления.
- `LinkTypeLegend` — легенда на графе с фильтрацией по типу и минимальному весу.

## API

### Создать связь

```bash
POST /api/v1/links
{
  "source_note_id": "uuid-1",
  "target_note_id": "uuid-2",
  "link_type": "reference",
  "weight": 0.8
}
```

### Обновить связь

```bash
PUT /api/v1/links/:id
{
  "link_type": "dependency",
  "weight": 0.9
}
```

### Данные графа

Ответы `/api/v1/graph/all`, `/api/v1/notes/:id/graph` теперь содержат:

```json
{
  "id": "uuid",
  "source": "uuid-1",
  "target": "uuid-2",
  "weight": 0.8,
  "link_type": "reference",
  "source_type": "user",
  "last_weight_update": "2026-07-29T12:00:00Z"
}
```
