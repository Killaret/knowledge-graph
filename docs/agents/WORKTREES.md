# Рабочие каталоги (worktree)

Канонический документ: какой каталог чей, на какой ветке, что проверять на старте сессии, что делать
при отставании и кто сливает ветки. Остальные документы ссылаются сюда, а не пересказывают. Постановка
— [`../tasks/WORKTREE-1-agent-worktrees.md`](../tasks/WORKTREE-1-agent-worktrees.md). Сверено с
`git worktree list` на машине владельца 2026-09-27.

## Карта

| Путь | Владелец | Назначение | Ветка |
|---|---|---|---|
| `D:\knowledge-graph` | человек | основной клон; слияние `ai-agents → main` | `main` |
| `D:\knowledge-graph-ai-agents` | Devin | реализация | `ai-agents` |
| `D:\knowledge-graph-review` | Claude Code | ревью, постановки, документы | отцеплённый `HEAD` на `origin/ai-agents` |

Во время переноса коммитов (`git rebase`) `HEAD` любого каталога переходно отцеплён, и `git worktree list`
показывает `(detached HEAD)` — это норма переноса, а не поломка.

Временные каталоги для проб — в `D:\kg-build-cache\` (решение 57). Создаются
`git worktree add --detach <путь> <коммит>` и удаляются `git worktree remove <путь>` сразу после работы.

## Ветки

- **`main` — только человек.** Слияние `ai-agents → main` — через PR, по его решению. Агенты в `main`
  не коммитят и не пушат.
- **`ai-agents` — общая ветка агентов.** Пушат оба; принудительный пуш запрещён.
- **Документы доски** и то, как они сливаются между ветками, — правило «Доска и её документы берутся из
  `ai-agents`» в [`../AI_AGENT_PROTOCOL.md`](../AI_AGENT_PROTOCOL.md).

## Старт сессии

Команды выполнены на этой машине 2026-09-27:

```
node scripts/testing/check-agent-session-tree.mjs .
git fetch origin
git status -sb
git worktree list
git log --oneline -1 origin/ai-agents
```

1. Дерево чистое — иначе сессия не начинается (`kg-work`, шаг 0).
2. `git status -sb` показывает ветку и отставание от `origin`.
3. `git worktree list` совпадает с картой выше; расхождение — сообщить владельцу.
4. Хеш `HEAD` идёт в строку «Прочитано» на доске; при синхронном дереве он равен `origin/ai-agents`.

Каталог Claude Code дополнительно: `git log --oneline origin/ai-agents..HEAD` пуст — незапушенных
коммитов нет, — затем `git checkout --detach origin/ai-agents`.

## Отставание и расхождение

| Случай | Что делать |
|---|---|
| ветка отстала, своих незапушенных коммитов нет | обновиться только перемоткой: `git merge --ff-only origin/ai-agents` (в отцеплённом каталоге — `git checkout --detach origin/ai-agents`) |
| пуш отклонён: `origin` ушёл вперёд, свои коммиты не запушены | перенести свои коммиты поверх: `git fetch`, `git rebase origin/ai-agents`; конфликт в документах доски — сохранить обе стороны (правило протокола); сторожа `check-decisions`, `check-tasks-index`, `check-board-limits`, `check-board-size`, `check-docs-links`, `check-spec-audit-1-register`; затем пуш |
| конфликт в коде, а не в документах доски, или чужая история переписана | остановиться и сообщить владельцу; молча не сливать и не переносить |

## Слияние `main` и `ai-agents`

Только человек или по его явному поручению. Как решаются конфликты документов доски — правило протокола
(ссылка выше).

## Чужие прогоны и данные

- **Перед действием, которое может убить чужой прогон** (остановка Docker, WSL, стеков), — проверка
  процесса агента, правило «Жив ли другой агент» в [`../AI_AGENT_PROTOCOL.md`](../AI_AGENT_PROTOCOL.md).
- **Тест-стенд общий** по именам контейнеров. Поднимать его только через `scripts/testing/start-test.ps1`:
  чужой стенд он не трогает. Когда можно брать чужой стенд с `-Force` — правило в
  [`../operations/TESTING.md`](../operations/TESTING.md).
- **Personal-стек** — только по явной просьбе человека ([`../../CLAUDE.md`](../../CLAUDE.md),
  `.windsurfrules`).

## Вопрос владельцу — форма каталога Claude Code

**Как сейчас.** Каждая сессия начинается с `git fetch` и `git checkout --detach origin/ai-agents`;
коммиты делаются на отцеплённом `HEAD`, пуш — `git push origin HEAD:ai-agents`; при отказе — перенос
своих коммитов поверх. 26–27.09 так прошло несколько десятков пушей, в том числе на фоне параллельных
пушей Devin.

| Вариант | За | Против |
|---|---|---|
| **A. Отцеплённый `HEAD`** — как сейчас | старт всегда с состояния `origin`; нет залежавшейся локальной ветки; цель пуша задана явно | `git status` не показывает, насколько каталог впереди `origin`; незапушенный коммит легко потерять при переключении — спасают `reflog` и проверка `origin/ai-agents..HEAD` на старте |
| **B. Локальная ветка `review`**, следящая за `origin/ai-agents` | `git status` показывает «впереди на N» | ветка залёживается и расходится; соблазн `git pull` с коммитами слияния; лишнее имя |

Предложение Claude Code: оставить A с обязательной проверкой `origin/ai-agents..HEAD` на старте. Решает
владелец.
