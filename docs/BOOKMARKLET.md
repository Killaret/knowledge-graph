# Knowledge Graph Bookmarklet

Букмарклет (bookmarklet) — это закладка в браузере, которая захватывает **заголовок страницы**, **URL** и **выделенный текст** и создаёт из них заметку в Knowledge Graph.

## Установка

1. Откройте файл `docs/bookmarklet.js`.
2. Замените `YOUR_DOMAIN` на адрес вашего сервера Knowledge Graph, например:
   - `https://kg.example.com`
   - `http://127.0.0.1:5173` (для локальной Vite-разработки)
3. Скопируйте значение константы `BOOKMARKLET` **без кавычек**.
4. В браузере создайте новую закладку:
   - Chrome: `Ctrl+D` → «Дополнительные» → вставьте скопированный код в поле URL.
   - Firefox: `Ctrl+D` → вставьте код в поле адреса.
5. Сохраните закладку, например, с именем **Save to KG**.

## Использование

1. Откройте любую страницу.
2. Выделите нужный текст.
3. Нажмите на закладку.
4. Откроется новая вкладка Knowledge Graph, и заметка будет создана автоматически.
5. Если вы не залогинены, система перенаправит на страницу входа, а после входа — создаст заметку.

## Как это работает

Букмарклет не обращается к API напрямую. Он просто открывает страницу `/import` с параметрами:

```
/import?title=<заголовок>&url=<адрес>&text=<выделенный текст>
```

Страница `/import` сама вызывает `POST /api/v1/import/bookmarklet` и создаёт заметку. Благодаря этому не нужно решать проблемы CORS, доступа к кукам и ограничений расширений браузера.

## API endpoint

- `POST /api/v1/import/bookmarklet`
- Авторизация: JWT (`Authorization: Bearer <token>`) или HttpOnly cookie `access_token`.
- Тело запроса:

  ```json
  {
    "title": "Page title",
    "url": "https://example.com/page",
    "text": "Selected text (optional)",
    "type": "asteroid"
  }
  ```

- Ответ `201`:

  ```json
  {
    "note_id": "...",
    "title": "Page title",
    "type": "asteroid"
  }
  ```

Полная спецификация endpoint — в `backend/openAPI.yaml` (`/api/v1/import/bookmarklet`).

## Ограничения

- **Длина URL:** общий размер URL с параметрами ограничен браузером (примерно 2000 символов). Если выделенный текст слишком длинный, часть может потеряться.
- **Авторизация:** для создания заметки необходимо быть залогиненным в Knowledge Graph.
- **Контент:** выделенный текст + заголовок + URL сохраняются как Markdown в теле заметки.
- **Тип:** создаваемая заметка получает тип `asteroid`.

## Кастомизация

Можно изменить в коде `window.open(..., '_blank')` на текущий домен и протокол. Для локальной разработки используйте `http`, для продакшена — `https`.
