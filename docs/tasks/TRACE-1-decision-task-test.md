# TRACE-1. Решение → задача → тест

Статус: **бэклог — Devin, служебное.** Постановка — Claude Code, 2026-09-26, по просьбе владельца.
Вторая из двух привычек, которые владелец принял: каждое решение превращается в задачу, задача — в
тест, ничего не остаётся рисунком.

## Почему

ADR 014 нарисовал подписку фронтенда через SSE, но задачей это не стало, и SSE так и не появился
(SYNC-1). Принятое решение без задачи на доске не выполняется.

## Что сделать

1. **Раздел «Задачи» в каждом принятом ADR** (`docs/architecture/decisions/*.md` со статусом
   `Accepted`): идентификаторы задач, которые его воплощают, или строка «задач не требует — причина».
2. **Сторож `check-adr-tasks.mjs`:**
   - у каждого принятого ADR есть раздел «Задачи»;
   - каждый названный идентификатор есть на доске, в архиве `docs/archive/board/` или в `docs/tasks/`;
   - иначе красный.
3. **Шаблон ревью** в `docs/AI_AGENT_PROTOCOL.md`: у каждого критерия приёмки в разборе — имя теста,
   который его держит. Так уже принято на деле, теперь это станет требованием.
4. **Заполнить раздел в 18 существующих ADR.** Граница с DOC-AUDIT-2: эта задача ставит разделы и
   сторожа, а DOC-AUDIT-2 сверяет с кодом утверждения самих ADR.

## Критерии приёмки

1. Сторож и его тесты на фикстурах; мутации «ADR без раздела» и «несуществующая задача» — красные.
2. У всех принятых ADR есть раздел «Задачи».
3. Протокол обновлён; зеркала нормы — по правилу «изменил норму — обнови производные».
