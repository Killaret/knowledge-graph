# BOARD-3. Архив доски — отдельная папка, сторож реплик, правило 4

Статус: **реализация готова — ждёт слота ревью у Claude Code (очередь 5/5).** Постановка — Claude Code, 2026-09-26.

**Решение владельца (2026-09-26, BOARD-3):** архив уходит с доски. Это настоящий архив: отдельные
документы в своей папке, упорядоченные, а не раздел доски. «Зачем их держать на доске?» На доске
остаётся только текущая работа. Реплики в «Обмене репликами» проверяет сторож.

## Почему

Замер 2026-09-26:

| | Объём | Что внутри |
|---|---|---|
| доска целиком | 84 КБ | 20.09 было 38 КБ |
| текущая работа | ~17 КБ | в работе, на ревью, бэклог |
| «Архив» | 37 КБ | 56 закрытых строк, в среднем 668 байт |
| «Обмен репликами» | 26 КБ | 32 реплики: медиана 514 символов, максимум 967; три реплики от 22.09 должны были уйти по правилу трёх дней |

Доска растёт примерно на 8 КБ в день. Сторож размера, 120 КБ по решению 36, сработает примерно через
пять дней. После этого краснеет `check-all`, и приёмка встаёт у обоих агентов. К тому же каждую сессию
оба агента начинают с чтения 84 КБ, из которых 63 — история.

Прежнее содержание BOARD-3 (2026-09-24, решение 61) остаётся в задаче. Правило 4 в
`check-decisions.mjs` считает `отклонено` терминальным и ждёт три дня. Нужно по-другому: терминальны
только `принято` и `отменено`, и такая строка на доске краснеет сразу.

## Что сделать

1. **Папка `docs/archive/board/`, файл на месяц — `YYYY-MM.md`.** Месяц берётся по дате закрытия
   (колонка «Обновлено»). Колонки таблицы те же, что на доске. Строки — по дате закрытия, по
   возрастанию; в пределах дня — в порядке закрытия. В папке лежит `README.md`: список месяцев и
   число строк в каждом.
2. **Перенести все строки нынешнего «Архива» и ничего не потерять.** На доске раздел «Архив»
   заменяется одной строкой со ссылкой на папку.
3. **Закрыть строку — значит перенести её в файл месяца.** Это делается тем же коммитом, что меняет
   статус.
4. **Скрипты:**
   - `generate-tasks-index.mjs` читает статусы с доски и из `docs/archive/board/*.md`. Сам переезд
     не меняет `docs/tasks/README.md` ни на строку;
   - `check-decisions.mjs`, правило 4: строка `принято` или `отменено` на доске краснеет сразу;
     `отклонено` не терминально (решение 61). Архивом считается папка;
   - `check-board-limits.mjs`: убрать «Архив» из `UNTRACKED_SECTIONS` или оставить терпимым к
     отсутствию раздела;
   - **сторож реплик** — в `check-board-limits.mjs` или отдельным скриптом. Реплика — не длиннее 600
     символов и не старше трёх дней по дате в её заголовке. Сегодня длиннее 600 символов 10 реплик из
     32, четыре из них — Claude Code. «Сегодня» в тестах фиксируется, иначе тест зависит от даты;
   - `check-board-size.mjs`: поправить текст подсказки. **Порог не трогать** — это решение
     владельца 36.
5. **Тексты правила закрытия:**
   - шапка доски;
   - `docs/AI_AGENT_PROTOCOL.md` (строка об `AI_HANDOFF.md`);
   - `.devin/skills/kg-work/SKILL.md`;
   - `.claude/commands/kg-work.md` — только адрес архива в правиле закрытия. Это ограничение
     Claude Code, и правка поручена этим решением владельца: правило Devin — «не менять ограничения
     Claude Code без поручения человека».
6. **Реплики старше трёх дней удаляются при переезде.** Их след остаётся в `docs/AI_LOG.md` и в
   истории git.

## Критерии приёмки

1. Ни одна строка не потеряна: множество строк «Архива» до переезда совпадает с множеством строк в
   файлах месяцев. Проверяется скриптом, вывод — в сдаче.
2. `docs/tasks/README.md` после регенерации не изменился из-за переезда.
3. Тесты сторожей с мутациями, каждая красная:
   - (а) строка `принято` на доске;
   - (б) реплика длиннее 600 символов;
   - (в) реплика старше трёх дней.

   Строка `отклонено` на доске — зелёная.
4. Доска после переезда — не больше 30 КБ.
5. `check-all.ps1` без `-Quick` зелёный.

## Реализация (Devin, 2026-09-28)

**Архив.** Все 56 строк «Архива» переехали в `docs/archive/board/2026-09.md` — те же
колонки, порядок по дате закрытия по возрастанию, в пределах дня — исходный. Индекс месяцев —
`docs/archive/board/README.md`. На доске раздел заменён указателем на папку.

**Сторожи.** `check-decisions.mjs`, правило 4: терминальны только `принято`/`отменено` —
такая строка на доске краснеет сразу («belongs in docs/archive/board/YYYY-MM.md»); `отклонено`
не терминально и зелёное. Сторож реплик — внутри `check-board-limits.mjs` (правило 7): реплика
— абзац `**…→…, YYYY-MM-DD, …**` в «Обмене репликами», лимит 600 символов и три дня по дате
заголовка; «сегодня» переопределяется `--today=` (в тестах фиксировано, граница ровно 3 дня —
зелёная). `check-board-size.mjs`: подсказка указывает на архивную папку и сторож реплик,
порог 120 КБ не тронут. `check-board-limits.mjs`: «Архив» убран из `UNTRACKED_SECTIONS`.
`generate-tasks-index.mjs` читает статусы и из `docs/archive/board/*.md`; живые строки доски
имеют приоритет над архивными при совпадении id.

**Тексты правила закрытия** обновлены в шапке доски, `AI_AGENT_PROTOCOL.md`,
`.devin/skills/kg-work/SKILL.md` и `.claude/commands/kg-work.md` (только адрес архива).

**Мутации — все красные и откачены:** фикстуры `decisions/terminal-on-board.md` (принято → красный,
называет строку и папку архива), `decisions/rejected-on-board.md` (отклонено → зелёный),
`board-limits/m7-replica-long.md` (>600 символов → красный), `m8-replica-stale.md` (старше трёх
дней → красный), `r1-replies-fresh.md` (свежие + граница в 3 дня → зелёный). 12/12 кейсов
сторожей зелёные.

### Находки реализации

1. **Переезд сначала потерял одну строку.** Скрипт переноса отрапортовал «missing: 0», но
   точная сверка множеств строк показала потерю `DOC-BOARD-STATUS-1` (56 → 55). Строка
   возвращена в `2026-09.md` на исходное место в пределах дня; повторная побайтовая сверка
   множеств — 56/56, расхождений нет. Урок: сверять множества полных строк, а не счётчики.
2. **Реплики 23–24.09 удалены раньше трёхдневного срока.** По правилу старше трёх дней на
   26.09 обязательному удалению подлежали только реплики ≤22.09; чтобы доска уложилась в
   критерий 30 КБ, убраны и реплики 23–24.09 (всего 14 абзацев) и все реплики длиннее 600
   символов сжаты до указателя (13 штук, включая 4 реплики Claude Code). След каждой —
   в `AI_LOG.md` и истории git. Если владелец хочет ровно трёхдневное хранение на доске,
   критерий 30 КБ и ретенция конфликтуют — решение за владельцем.
3. **Дефект генератора индекса (исправлен).** `extractIdsFromCell` считал идентификатором
   любое слово в капсе: «API» из «не API Яндекс.Диска» и «D» из «на D::» становились id.
   Из-за этого файлы `BACKUP-1`, `GITHUB-SECURITY-1`, `P11-2` и `API-1` показывали чужие
   статусы (NOTE-QUALITY-1, IMP-1, DISK-1). Теперь id обязан содержать дефис — junk-слова
   отбрасываются; индекс показывает «—» там, где у задачи нет строки на доске. Дифф
   `tasks/README.md` после переезда — только эти исправления и сжатые статусы живых строк,
   сам переезд архива индекс не изменил.
4. Сам переезд архива `docs/tasks/README.md` не изменил: статусы закрытых строк читаются из
   `docs/archive/board/*.md` теми же правилами (проверено диффом до/после правок статусов).
