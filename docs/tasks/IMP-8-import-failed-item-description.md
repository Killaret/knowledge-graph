# IMP-8. Массовый импорт: описание «что это» для упавших и стабовых ссылок

**Статус: бэклог.** Зафиксировано по просьбе владельца 2026-09-18, реализация не начата.

## Контекст

IMP-7 добавил опцию «только заголовок» для error-строк превью. При ручном разборе `bookmarks_18.09.2026.html` выяснилось, что одного заголовка мало: владельцу нужны заметки вида «что это за ресурс + ссылка». Devin вручную создал 16 таких заметок (10 пустых + 6 стабовых элементов очереди): Coursera-курсы по слагу URL, «крипто-обменник», «онлайн-школа», «дизайн-файл Figma» и т.п.

Формулировка владельца: «при импорте надо дать команду — оставить заголовок, написать что это, каким-то образом извлечь что это, всё записать».

## Требования

1. **Поле описания у error-строк.** При включённом «только заголовок» (IMP-7) показывать текстовое поле «что это» — введённое описание уходит в `text` элемента импорта вместо пустоты. Бэкенд менять не нужно: `importItem.text` уже принимает произвольный текст, `ProcessImportTask` пишет его в контент.
2. **Подсветка стабов.** Элементы, прошедшие фетч, но с тривиальным текстом (< ~200 символов после заголовка — стабы SPA/логинов/пейволов), помечать отдельным бейджем и давать ту же опцию описания. Сейчас они визуально неотличимы от нормальных.
3. **Автоподсказка описания (опционально, вторым шагом).** Источники в порядке приоритета:
   - слаг и путь URL (`/learn/software-processes/` → «Software Processes»);
   - заголовок закладки из файла (он уже есть в `title`);
   - meta `description`/`og:description`, если частичный ответ всё же пришёл;
   - позже — NLP/LLM-генерация по домену и заголовку.
4. **Дедуп сохранить.** Ручные/описанные заметки не должны конфликтовать с очередными элементами — `loadExistingSourceMap` уже дедупит по нормализованному `source_url`, поведение оставить.

## Замечания к реализации

- Точка входа: `frontend/src/routes/import/bookmarks/+page.svelte` (строка превью), хелперы `shared/utils/import-preview-items.ts`.
- «Стаб» — эвристика на фронте по длине `text` из ответа превью; не путать с error-строками.
- Связано: IMP-7 (title-only opt-in), IMP-6 (batch-пайплайн), NOTE-QUALITY-1 (критерий качества заметки — стабы пересекаются с ним).

## Проверено вручную (2026-09-18)

16 заметок созданы через `/api/v1/import/bookmarklet` с title+описание+URL; очередные элементы с теми же `source_url` отвалятся дедупом при запуске воркера. Пустых/стабовых ссылок из файла не осталось.
