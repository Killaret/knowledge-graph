# Ревью UX-2 (Claude Code, 2026-09-13)

**Принято.** Самое важное в этой задаче — не страница 500, а баг, найденный по дороге.

## Баг авторизации на клиенте

`+layout.svelte` считал маршрут публичным по `currentPath.startsWith("/")` — то есть
**любой** путь. Редирект на `/auth/login` для приватных страниц не срабатывал никогда.
Сервер при этом отвечал 401, так что утечки данных не было; ломался только пользовательский
путь — вместо формы входа человек видел пустую страницу с ошибками API.

Исправление вынесено в `shared/utils/route-match.ts`: `currentPath === route ||
currentPath.startsWith(route + "/")`. Регрессионный тест есть, и он ловит именно этот
баг — проверил мутацией, вернув `startsWith(route)`:

```
× does NOT treat every path as public because of '/'
× does NOT match partial path segments
```

Второй сценарий — бонус: `/notes-archive` больше не считается подмаршрутом `/notes`.

## Страница 500

`+error.svelte` — 184 строки, `position: fixed; inset: 0`, i18n-ключи `error.500.*`,
иллюстрация `server-error` для 5xx, stack trace только под `import.meta.env.DEV`.
`error-page.spec.ts` — 4/4 зелёные. Аудит обработки ошибок в постановке честный: граф
и виджеты ловят ошибки локально намеренно, и это правильное решение — падение графа
не должно уносить остальной интерфейс.

## Мелочь

- **Тестовый маршрут в продакшене.** `src/routes/test/500/+page.server.ts` бросает 500
  по `?trigger=500` и ничем не ограничен — в собранном приложении он есть. Вреда мало:
  это просто страница ошибки. Но это тестовый артефакт в поставке, и каталог
  `routes/test/` стоит либо вырезать из production-сборки, либо гейтить переменной
  (`APP_ENV=test`), а не `import.meta.env.DEV` — Playwright ходит к собранному стеку.
- Критерий «CI полностью зелёный» в постановке не отмечен, хотя CI зелёный с `bf22662`
  (см. `CI-MAIN-1-review-findings.md`). Галочку ставлю.
