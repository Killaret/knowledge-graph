## Живой контракт

`POST /extract_keywords` на `kg-test-nlp` (сборка с этой ветки):

```
extractor: keybert-hybrid-0.9
  дерево индекс            surface=деревья индексов          w=0.612
  выбирать индекс          surface=выбирает индексы          w=0.599
  индекс строиться         surface=индексы строятся          w=0.591
```

`keyword` — лемма, `surface` — как в тексте, `extractor` в ответе и в `/health`. Лемматизация
русского работает: деревья → дерево, индексов → индекс, ускоряют → ускорять.

Латентность в установившемся режиме (три прогона каждый): короткий русский текст 136–207 мс,
английский 144–265, **9 900 символов — 1 356–1 571 мс**. Первый вызов после старта — 3 206 мс
(прогрев). Запас до таймаута клиента в 10 с — шестикратный. Замер Devin подтверждается.

## Сторож лицензий — обе ветки

- `yake==0.4.8` дописан в `requirements.txt`, в инвентаре нет → `MISSING in LICENSES.md: yake`, FAIL.
- тот же пакет **внесён** в инвентарь с `GPL-3.0-or-later` → `COPYLEFT license: yake … -> GPL-3.0-or-later`, FAIL.

Ограничение по конструкции: колонку лицензии в инвентаре пишет человек; сторож проверяет
инвентарь, а не реальность. Пакет, вписанный с неверной лицензией (как `yake` с его «LGPLv3»
в метаданных), пройдёт. Это осознанная граница, записать её в шапку `LICENSES.md`.

таблицы чисел; вынести в незакоммиченный каталог. Решает владелец.

## Наблюдение по качеству — не блокер

Биграммы `(1, 2)` с глаголами, приведёнными к инфинитиву, — плохие теги:
`postgresql ускорять`, `выбирать индекс`, `choose index`, `index use`. Для узла графа нужна
именная группа. `pymorphy3` отдаёт часть речи бесплатно (`parsed[0].tag.POS`), WordNet — тоже;
фильтр «оставлять кандидатов, где голова — существительное» дешёв и снимет большую часть
мусора. Постановка этого не требовала — отдельной задачей, после того как владелец посмотрит
top-10 в `measurements.md` глазами.

## Принято без замечаний

- Гибрид как в постановке: статистический шорт-лист по всему тексту → ранжирование моделью по
  кускам; `candidates=` в keybert, не `nr_candidates`.
- `runPostSteps` вынесен в `internal/infrastructure/recompute` и переиспользован обоими
  `*-recompute` — постановка это просила, чтобы не плодить копии.
- Строка версии экстрактора — одна константа в NLP-сервисе, отдаётся в `/health`, `keyword-recompute`
  её оттуда и читает, а не дублирует.
- Миграция 031: `surface` и `extractor` с умолчанием `yake-0.4.8` для старых строк; `down`
  честно говорит, что данные не откатываются.
- `docs/LICENSES.md` — 79 записей по трём сервисам, с источником у каждой.
