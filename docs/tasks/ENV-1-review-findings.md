# Ревью ENV-1 (Claude Code, 2026-09-14)

**Принято.** Проверено запуском с нуля, а не чтением скрипта.

## Что было

`docker-compose.test.yml` читал `${JWT_SECRET}`, `start-test.ps1` эту переменную не
задавал, `.env` в репозитории нет. На чистой машине compose подставлял пустую строку
и лишь ронял `warning ... Defaulting to a blank string`, а `backend` и `worker` уходили
в бесконечный рестарт с `FATAL: JWT_SECRET must be set`. Скрипт при этом ждал здоровья
контейнеров и ничего внятного не говорил.

Это тот самый сценарий второго компьютера, про который владелец спрашивал в сентябре.

## Проверено исполнением

Стек погашен с `-v`, переменная в окружении **не задана** (проверено явно), запуск
`start-test.ps1` с нуля:

```
All containers are healthy!
kg-test-backend   Up (healthy)   127.0.0.1:18083->8080/tcp
kg-test-worker    Up (healthy)
... всего 9 контейнеров, все healthy
```

`GET /health` → **200**.

## Три варианта поведения — все три верны

| Ситуация | Ожидание | Факт |
|---|---|---|
| переменной нет нигде | берётся дефолт | `test-jwt-secret-32-characters-long` |
| переменная задана в окружении | **не затирается** | `my-own-custom-secret-32-characters!!` |
| лежит `.env.test` | читается из файла | `secret-from-dotenv-file-32-chars!` |

Второй случай — самый важный из трёх и самый лёгкий испортить: скрипт, который
«на всякий случай» выставляет дефолт безусловно, молча ломает всем, у кого свой секрет.
Здесь порядок правильный: сначала процесс, потом файл, потом дефолт.

`.env.test.example` заведён, реальный `.env.test` в `.gitignore` (строки 41–42) —
то есть пример в репозитории есть, а чужой секрет туда не уедет.

## Замечаний нет

Мелочь на будущее, не блокер: при подстановке дефолта скрипт печатает
`JWT_SECRET not set; using default test secret.` жёлтым — это правильно. Но compose
всё равно отдельно ругается на `YANDEX_CLIENT_ID` / `YANDEX_CLIENT_SECRET`. Они
безвредны для тестового контура, однако в общем шуме предупреждений легко пропустить
настоящее. Если когда-нибудь будет скучно — те же дефолты для них убрали бы шум.
