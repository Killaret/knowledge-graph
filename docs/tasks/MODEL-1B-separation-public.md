# MODEL-1B — разделимость папок, публичный корпус

Гипотеза владельца: e5-base за счёт большего окна/ёмкости может находить сходство там, где связи нет — «мосты» между чужими темами размывают границы. Здесь — публичный корпус 2100 документов (состав и сборка — в `MODEL-1B-public-findings.md`); приватный замер — `MODEL-1B-separation-findings.md`.

Метрика AUC: вероятность, что случайная пара из одной папки ближе случайной пары из разных папок (Mann-Whitney по всем парам оценочного множества). Выше — чище границы. Margin — медиана по заметкам разности «лучший сосед своей папки − лучший сосед чужой».

## Как читать и что вышло

На публичном корпусе картина обратная приватной: e5-base разделяет папки **лучше** e5-small во всех трёх парах — сырой C 0.718 против B 0.690, конвейер F 0.744 против E 0.738, без заголовка F′ 0.745 против E′ 0.734. Гипотеза размытия здесь не подтвердилась: на чистых длинных текстах ёмкость base работает на различение, а не на фантомы.

Что общего с приватным замером: D (чанкованный MiniLM) — лучший сепаратор и здесь (0.804), и чанкинг у e5 теперь повышает AUC (E 0.738 > B 0.690, F 0.744 > C 0.718), хотя p@3 на этом же корпусе был ниже — чанкинг разводит свои/чужие пары, но верхушку соседей сдвигает. Заголовок на AUC почти не влияет (F′ ≈ F) — у 2/3 корпуса его нет.

Сводная картина по корпусам: на маленьком шумном корпусе base размывает границы чуть сильнее (AUC ниже на ~0.02), на большом чистом — разделяет лучше. Оба замера советуют одно: для автосвязей решает калибровка порога под конкретную модель и конвейер, а не размер сам по себе.
