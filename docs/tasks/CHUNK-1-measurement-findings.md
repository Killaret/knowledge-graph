# CHUNK-1: замер прототипа чанкера — находки

**Дата:** 2026-09-21 · **Статус:** на ревью у Claude Code · **Связь:** `CHUNK-1-structure-aware-chunker.md` (открытые эмпирические пункты)

## Метод

Прототип чанкера по спеке CHUNK-1 в `nlp-service/scripts/measure_chunking.py`
(иерархия границ, инвариант ≤ max_tokens, forced_split при переполнении
единичного юнита). Корпус: 108 заметок владельца (локальный дамп, не в git).
Два контура: MiniLM-L12-v2 (текущий, окно 128) и multilingual-e5-base
(кандидат, окно 512).

|---|---|---|

## Выводы

1. **Усечение сегодня теряет четверть семантики.** cos(mean_agg, trunc@128)
   = 0.744 медиана; **82% заметок меняют top-2 соседей** при переходе на
   чанки — топология связей фактически построена на первых 128 токенах.
   Чанкер нужен уже на текущей модели, не только под e5-base.
2. **С e5 окно 512 почти снимает проблему** (0.963), но топология всё равно
   меняется у 68% — и скоры растут (0.88→0.92): чанкованный doc-вектор
   точнее, а не просто шире.
3. **Агрегация: mean достаточно.** Weighted (первый чанк ×2) почти не
   отличает результат (0.744→0.768 / 0.963→0.967) и смещает вектор к началу
   документа — частично воспроизводит усечение, которое чиним. **v1: mean.**
4. **Title-инъекция — не косметика:** меняет top-2 у 46% заметок и снижает
   медиану скора (0.921→0.897). Уникальный title растаскивает похожие
   заметки — вероятно, срезает ложные связи от общего бойлерплейта, но
   без ground truth «лучше/хуже» не доказать. Владелец склоняется к «да»;
   взаимодействие с `GAMMA_LINK_MIN_SCORE=0.6` учесть (медиана 0.897 >>
   порога, связи выживают).
5. **forced_split коррелирует с окном:** 128 при max=128 vs 2 при max=512 —
   длинные непунктуированные прогоны (веб-выгрузки) — главный источник
   вынужденных разрезов. На e5 почти исчезает.
6. **Найден класс stub-заметок:** 9/108 (~8%) — контент = одна строка
   `## [title](url)` (heading-only, длина ≥100 набрана URL). Чанкер вернёт
   0 чанков — пайплайн должен помечать «нет контента», а не эмбеддить
   пустое. Сигнал для NOTE-QUALITY-1.
7. **Оценка качества миграции (решение 51, 2026-09-21):** сейчас —
   дельта-разметка ~25 пар «старый сосед → новый сосед», владелец
   размечает «было лучше / стало лучше / оба мимо»; после готовности
   контура качества — полный размеченный корпус с подготовкой корректных
   данных, все замеры перепрогоняются (см. «срок годности» выше).

## Рекомендация в спеку

- v1: mean-агрегация, title-инъекция включаемой по решению владельца
  (данные: сдвиг 1.4% на e5, меняет топологию у ~половины).
- Stub-детекция «content = только заголовок-ссылка» — отдельный сигнал
  качества, не чанкера.
- Срок годности: перепроверить после NOTE-QUALITY-1 (корпус изменится).
