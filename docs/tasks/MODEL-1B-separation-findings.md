# MODEL-1B — разделимость папок (сепарация)

Гипотеза владельца: e5-base за счёт большего окна/ёмкости может находить сходство там, где связи нет — «мосты» между чужими темами размывают границы. Проверка на тех же 76 заметках с папками.

Метрика AUC: вероятность, что случайная пара из одной папки ближе случайной пары из разных папок (Mann-Whitney по всем парам оценочного множества). Выше — чище границы. Margin — медиана по заметкам разности «лучший сосед своей папки − лучший сосед чужой».

## Как читать и что вышло

Гипотеза подтвердилась по направлению: e5-base разделяет папки **хуже** e5-small во всех трёх парных сравнениях — сырой C 0.771 против B 0.793, полный конвейер F 0.765 против E 0.786, без заголовка F′ 0.728 против E′ 0.756. Margin med тоже систематически ниже у base. То есть ёмкость base действительно поднимает близость чужих пар (inter-med у e5 ~0.79–0.84 против 0.23 у MiniLM) — границы размываются.

Как это уживается с тем, что F выиграл E по p@3 (0.583 против 0.548): AUC меряет весь ряд пар, p@k — только верхушку. Base в среднем поднимает чужие пары сильнее, но свои самые близкие пары всё равно ставит чуть выше. Для автосвязей по порогу размытие важнее точности верхушки: при inter-med ~0.80 фиксированный порог 0.85 пропустит массу фантомов у любой e5, а у base их больше.

Лучший сепаратор — D (чанкованный MiniLM, 0.805): нормализация+чанкинг реально чистят. У e5 чанкинг сепарацию не улучшил (E < B, F < C), без заголовка хуже ещё — на этом корпусе заголовок несёт сигнал папки.
