# A-3. Замечания ревью

Ревьюер: Claude Code. Исполнитель: Devin. Предмет: правки в `scripts/testing/run-full-test-cycle.ps1` и `run-full-test-cycle.sh` по задаче A-3.

Статус: **не принято, есть блокер.**

## Блокер

`run-full-test-cycle.ps1`, финальная агрегация:

```powershell
$anyFailed = $script:PhaseResults.Values -contains 1
```

`-contains 1` ловит только код выхода, равный единице. Проверено на pwsh:

```
anyFailed при exit=2 : False
anyFailed при exit=1 : True
```

`go test` при панике отдаёт 2, `pytest` — 2, 4 или 5, `docker compose` — 125, 126, 127. При таком коде `[Final Summary]` печатает по фазе `[FAIL]`, а шапка сообщает `TEST CYCLE COMPLETE`, и скрипт завершается нулём. Это тот же дефект, ради устранения которого задача и ставилась, просто срабатывающий реже.

Замена:

```powershell
$anyFailed = @($script:PhaseResults.Values | Where-Object { $_ -ne 0 }).Count -gt 0
```

**Про способ проверки.** Предложенная подмена `seed-test-data.ps1` на `exit 1` этот дефект не поймает: с кодом ровно 1 проверка пройдёт. Стенд должен падать с кодом **2**.

## Мелкое

1. `Register-Phase` завершается `return $ExitCode -eq 0`, а вызывается как обычная команда — булево уходит в поток вывода, и после каждой фазы печатается лишняя строка `True`. Убрать `return` либо погасить через `$null =`.
2. В `run-full-test-cycle.sh` провал сидирования (около строки 107) не выставляет `any_failed`, тогда как в `.ps1` эта фаза регистрируется. Поведение версий должно совпадать.
3. Нумерация шагов рассинхронизирована: ранние шаги остались `[Step 4/28]`, очистка стала `[Step 27/27]`.

## Принято без замечаний

Структура `Register-Phase` / `Write-FinalSummary` / `Stop-TestCycle`; `throw` вместо `exit 1` внутри `try`, чтобы отчёт печатался из `catch`; сохранённый `finally` с остановкой тест-стека и восстановлением стеков; полная чистка автокоммита, `git add -A` и маркера «successful regression cycle» в обеих версиях; чистые `bash -n` и разбор pwsh.

Прогон с фазой, падающей с кодом выхода 2, завершается ненулевым кодом, шапка отчёта показывает `TEST CYCLE FAILED`, и эта фаза помечена `[FAIL]`. Приложить вывод прогона.
