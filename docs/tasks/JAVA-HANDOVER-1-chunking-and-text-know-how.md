## Предусловие — CHUNK-PERF-1, Devin

Строка 4 чинится в Python до передачи: переносить в Java нужно исправленный алгоритм. Постановка —
[`CHUNK-PERF-1-long-paragraph.md`](CHUNK-PERF-1-long-paragraph.md): обычная проза одним абзацем в
400 КБ режется 11,6 с, абзац из «www.» того же размера — 94 с.

## Что сделать

1. Пакет для Java-разработчика — один документ: правила без привязки к Python, параметры, крайние
   случаи. К каждому правилу — пример «вход → выход» из наших тестов.
2. Сверка с ТЗ: где наше правило расходится с ТЗ, расхождение уходит владельцу, а не
   исправляется молча.
3. В ТЗ — ссылка на пакет.

## Критерии приёмки

1. Каждая строка перечня есть в пакете со ссылкой на источник: файл и строка или коммит.
2. Примеры «вход → выход» взяты из тестов и совпадают с их прогоном.
3. Для медленных шаблонов — строки-атаки и замеры «было / стало».
4. Расхождения с ТЗ перечислены и переданы владельцу.

## Когда

NOTE-QUALITY-1 сейчас в доработке. Замеры CHUNK-1 и NLP-4 годны только для текущего корпуса
(CHUNK-1, «Срок годности замеров») и передаются с этой оговоркой.
