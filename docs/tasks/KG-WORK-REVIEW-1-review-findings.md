## Мелочи — не блокеры

1. **`triggers:` у `kg-new-chat` — `user` + `model`**, у соседних (`kg-regression`) только `model`.
   Похоже на намеренное: скилл вызывается и человеком, и по событию конца задачи. Схемой не
   нарушено — оставлено как есть.
2. **Шаг 4 скилла** предлагает первую фразу «`/kg-work`, следующей строкой — «берём \<задача\>»».
   Лёгкое трение с «режим выбирает агент»: строка-подсказка полезна, но новая сессия всё равно
   выбирает режим по доске. Не конфликт — подсказка не обязывает.
3. **`WORKTREES.md` «Отставание» предписывает `git rebase`**, в этой сессии был сделан `git merge`
   — результат по содержимому тот же, но история получила merge-коммит. Не дефект правок; помечаю
   свою же девиацию, чтобы следующий раз был rebase.
4. **`git commit *` в allow** позволяет `--amend`/`-a`; в чистом дереве сессии забирать нечего, а
   незапушенный `--amend` — безвреден. Покрыто сторожем авторства.
