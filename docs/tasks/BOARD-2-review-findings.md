## Мелочи — не блокеры

1. `firstStatusWord` принимает `принято (доработка)` и `принято с условием`, но статус вида
   `отклонено, заблокировано` (запятая сразу после слова) уйдёт в «вне словаря» с непонятным
   текстом ошибки. По букве постановки это верно — первое слово; текст ошибки стоит сделать
   «после статуса — пробел или скобка».
2. Строки короче четырёх колонок молча пропускаются — те самые обрывки `||` из 21.09 сторож не
   увидит. Одна строка `errors.push` на `parts.length < 4` в отслеживаемых разделах.
3. Раздел «Архив» не проверяется словарём — там уже есть `решено` (строка про
   `notes_dataset.json`). Не ошибка по постановке, но словарь тогда живёт в двух режимах.
