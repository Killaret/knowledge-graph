# NLP-4: замер итеративной нормализации — находки

**Дата:** 2026-09-21 · **Статус:** на ревью у Claude Code · **Связь:** `NLP-4-note-logical-form-normalization.md` (открытый вопрос: критерий остановки итераций)

## Метод

Харнес `nlp-service/scripts/measure_normalization.py`: до 4 проходов детерминированных правил нормализации (бойлерплейт, навигационные строки, дубли, cookie/marketing) над корпусом. Метрики: токены/символы по итерациям, распределение остановки при гипотезе «бюджет 3 + дельта <5%», деградации (<100 символов), косинусная близость эмбеддинга e5-base к исходнику.

**Корпус:** 113 заметок Personal-стека (экспорт read-only, контейнер потушен после дампа). Из них 108 ≥100 символов — проходят в замер, 5 отбрасываются как title-only stubs (правило пропуска из спеки работает).

## Выводы

1. **Итеративность не нужна.** Детерминированный ruleset достигает неподвижной точки за один проход: итерации 2–4 не изменили ни одной из 108 заметок. Гипотеза «до 3 проходов с дельта-стопом» эквивалентна одному проходу — второй запуск правил не находит нового мусора.
2. **Один проход + предохранители = рекомендуемый v1.** Останавливаться не по дельте, а сразу: проход → проверка результата → commit или откат.
3. **Предохранители работают:** 1 заметка («BingX», 141→67 символов) ушла ниже порога — откат сохраняет оригинал.
4. **Риск не в итерациях, а в агрессивности правил.** Худший дрейф эмбеддинга — 0.452 (страница товара MENS/Jacques Marie Mage): правила выкинули названия товаров как «навигацию», но оставили маркетинговый текст. Медиана дрейфа 1.000; заметные просадки (0.72–0.73) у выгрузок статей — там режется реальный бойлерплейт, смысл в целом сохранён.
5. **Порог деградации по символам недостаточен** — заметка может остаться длинной, но потерять смысл (см. п.4). Кандидат-страж: косинусная близость нормализованного текста к исходнику, откат при cos < ~0.7. Требует e5-эмбеддинга исходника — он и так считается в пайплайне, цена ≈ ноль. Решать на ревью спеки.

## Предлагаемая правка спеки

- v1: один детерминированный проход, `iterations` фиксируется = 1, `stop_reason` = `single_pass`.
- Предохранители: откат при `len(result) < 100` **или** `cos(emb(result), emb(source)) < 0.7` — оба сигнала пишем в `nlp_artifacts` для наблюдаемости.
- Итеративный режим не реализуем; если появится LLM-переписывание — тогда вопрос остановки вернётся.
