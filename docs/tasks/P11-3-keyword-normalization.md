## Остаток — две заметки без ключевых слов «полностью похожи»

Все четыре метрики в `keyword_similarity.go` — Жаккар, перекрытие, Тверски и взвешенный Жаккар —
для двух пустых наборов возвращают 1.0 («Оба пустые — полное сходство»). Сходство по ключевым словам
подключено к рекомендациям (`cmd/worker/main.go:211`, обход графа с весами), поэтому две заметки без
ключевых слов — голые ссылки, короткие записи — получают полный балл по ключевым словам и советуют
друг друга.

Владелец, 2026-09-17 (записано в NOTE-QUALITY-1): «две пустые заметки не похожи, они обе не готовы».

## Что сделать

1. Два пустых набора → 0.0 во всех четырёх метриках.
2. Один пустой набор → 0.0, как сейчас.

## Критерии приёмки

1. Тест на каждую метрику: два пустых набора — 0.0. Мутация «вернуть 1.0» — красная.
2. Тест на уровне сопоставления (`KeywordMatcherImpl.Match`): кандидат без ключевых слов у заметки без
   ключевых слов получает 0.
3. Строки «уже сделано» выше сверены с кодом исполнителем; расхождение — в разбор, а не молча.

## Разбор исполнения (Devin, 2026-09-28)

**Расхождение с постановкой.** В постановке «все четыре метрики» — в коде их **пять**: Жаккар,
перекрытие, Тверски, взвешенный Жаккар и **косинус** (`CosineSimilarity`). Все пять возвращали 1.0
на двух пустых наборах; исправлены все пять. Отдельно проверен клэмп косинуса
(`cosine > 1.0 → 1.0`) — это численная защита, не ветка пустых наборов, не трогал.

**Что изменено.** `keyword_similarity.go`: ветка `len(source)==0 && len(target)==0` возвращает 0.0
во всех пяти метриках (один пустой набор и раньше давал 0.0 — не менялся). Матчер не тронут:
`KeywordMatcherImpl` чисто передаёт результат метрики, спец-случаев добавлять не потребовалось.
Взвешенный Жаккар без весов деградирует до обычного — покрыт обоими путями.

**Сверка «уже сделано NLP-2» (критерий 3).** Подтверждено: pymorphy3/WordNet-лемматизаторы
(`nlp_utils.py:~168-177`), дедуп по лемме с сохранением лучшей поверхностной формы
(`nlp_utils.py:~357-358`), `note_keywords`: `Keyword` — каноническая лемма + `Surface` + `Extractor`
(`note_keyword_model.go:10-12`). Сдвиг номеров строк от постановки — файл вырос, содержимое на месте.

**Тесты.**
- Метрики: «both empty → 0.0» у Жаккара, перекрытия, Тверски, косинуса; у взвешенного Жаккара два
  случая — с пустыми картами весов и с `nil` (fallback в Жаккар).
- Матчер: `TestKeywordMatcherImpl_Match_BothEmptyKeywords` — источник и кандидат без ключевых слов →
  балл ровно 0.0.

**Мутации (красные).**
- «Jaccard: вернуть 1.0» → красные `TestJaccardSimilarity/both_empty`,
  `TestKeywordMatcherImpl_Match_BothEmptyKeywords` и оба случая взвешенного Жаккара (fallback живой).
- «Cosine: вернуть 1.0» → красный `TestCosineSimilarity/empty_sets`.
