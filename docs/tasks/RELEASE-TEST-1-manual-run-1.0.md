# RELEASE-TEST-1. Полный ручной прогон 1.0

Статус: **бэклог — 1.0; чек-лист готов, прогоны — на кандидате в выпуск.** Составил Claude Code,
2026-09-27, по плану в [`RELEASE-1-scope-1.0.md`](RELEASE-1-scope-1.0.md), раздел «Полное ручное
тестирование».

Один чек-лист на цикл 1.0: сложить, связать, найти, не потерять, 2D и 3D, кластеры, напоминания. У
каждого пункта — шаг, ожидание и задача, которая за него отвечает: находка сразу указывает, кому
чинить. Подробности интерфейса не повторяются — ссылки на разделы
[`MANUAL_TEST_CHECKLIST_COCKPIT.md`](../operations/MANUAL_TEST_CHECKLIST_COCKPIT.md).

## Два прохода

1. **Claude Code — тест-стенд.** `scripts/testing/start-test.ps1` с `SKIP_AUTH=false`, стандартный сид плюс
   импорт снимков золотого набора. Цель — отсеять очевидное, пока владелец не потратил время. Пункты,
   где нужен человеческий взгляд (читаемость, ощущение), помечаются «для владельца».
2. **Владелец — кандидат в выпуск на копии реальных данных.** Свежий бэкап Personal-стека
   ([`../operations/BACKUP.md`](../operations/BACKUP.md)) восстанавливается в отдельный стенд;
   Personal-стек не трогается. Заодно проверяются бэкап, восстановление и переход данных на 1.0.

Каждая находка — запись в [`../agents/MANUAL_TEST_FEEDBACK.md`](../agents/MANUAL_TEST_FEEDBACK.md) с
номером пункта и свидетельством. Блокер — пункт из состава 1.0 не работает; остальное — мелочь.
