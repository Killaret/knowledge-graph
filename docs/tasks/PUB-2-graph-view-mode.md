# PUB-2. Граф сообщества как режим просмотра, а не следствие авторизации

Постановка для Devin. Порядок работы: [`../AI_AGENT_PROTOCOL.md`](../AI_AGENT_PROTOCOL.md).

Ставит Claude Code, реализует Devin, проверяет Claude Code.

**Очерёдность:** после PUB-1. Опирается на открытое анонимное чтение.

## Зачем

Решение владельца: авторизация задаёт **значение по умолчанию**, а не запирает выбор.

Сейчас выбор жёсткий — `frontend/src/shared/api/graph.ts:253`:

```ts
const endpoint = isAuthenticated() ? "v1/graph/full" : "v1/graph/public";
```

Следствие: вернуться к графу сообщества, будучи залогиненным, невозможно. Люди, которые единственные могут пополнять сообщество, — ровно те, кто его не видит. И запланированные подграфы сообществ в такую схему не встают: чтобы участвовать в сообществе, надо его видеть, оставаясь собой.

## Что сделать

**Режим просмотра** с двумя значениями: «Мой граф» и «Сообщество». Умолчание — по состоянию сессии: аноним получает «Сообщество», авторизованный «Мой граф». Аноним переключиться не может, ему доступен один режим.

Выбор режима хранится там же, где живут прочие пользовательские настройки вида. Если такого места нет — `localStorage` достаточно, отдельную таблицу заводить не нужно.

Переключатель ставится рядом с существующими органами управления видом (2D/3D, список/граф) — отдельного места не изобретать.

Запрос выбирается по режиму, а не по `isAuthenticated()`. Авторизованный пользователь в режиме «Сообщество» ходит на публичный эндпоинт со своим токеном — это допустимо и ничего не ломает.

**Третий режим «Вместе» в эту задачу не входит.** Он требует решения, как визуально отличать чужие узлы от своих; решим отдельно.

## Ограничения

- Не менять состав данных публичного эндпоинта.
- Не трогать разделение периметра из AUD-5.
- Не переименовывать эндпоинты — это PUB-3, отдельной задачей, чтобы диффы не смешивались.
- Кэш графа ключуется так, чтобы ответы двух режимов не подменяли друг друга. Проверь `nocache` и хеш ответа.

## Критерии приёмки

1. Аноним по-прежнему видит граф сообщества и переключателя не имеет.
2. Авторизованный по умолчанию видит свой граф.
3. Авторизованный переключается на «Сообщество» и получает публичный граф: на сидированных данных 10 публичных узлов против 20 своих.
4. Выбор переживает перезагрузку страницы.
5. Обратное переключение возвращает свой граф — то есть режим действительно двусторонний.
6. **Проверено мутацией:** вернуть `isAuthenticated() ? ... : ...` вместо режима и убедиться, что тест на критерий 3 краснеет.
7. `npm run test:unit` и `npm run check` зелёные.

## Что приложить к результату

Числа узлов в обоих режимах под одной и той же сессией — это единственное доказательство, что переключатель действительно меняет источник, а не подпись на кнопке.
