# MODEL-1B findings — дозамер моделей на публичном корпусе

Дополнение к `MODEL-1B-findings.md` (замер на приватном корпусе, 108 заметок). Этот прогон — контрольный, на чистых публичных данных: проверяет, сохраняется ли вывод «e5 лучше MiniLM» и как меняется разрыв e5-small/e5-base на большом корпусе. Выбор модели для прода остаётся за владельцем — публичный корпус чище реальных заметок (нет стабов импорта и мусора HTML).

Корпус: 2100 заметок, из них 2100 с непустой папкой. Кандидаты для метрик — все 2100 заметок корпуса.

Источники (публичные HF-датасеты, `fetch_public_corpus.py`, seed 20260924, до 700 документов на источник, стратификация по категориям, тексты обрезаны до 4000 символов):
- `mteb/mlsum` ru train — русские новости, папка = тема (часть тем отображена на общие имена: sport, politics, business, science/tech, entertainment);
- `SetFit/bbc-news` train+test — английские новости, папка = категория (общие имена с mlsum, чтобы кросс-языковые связи по теме считались верными);
- `mteb/GeoreviewClusteringP2P` test — русские отзывы, папка = `geo:<категория>` (50 категорий).

Итого 67 папок. Ограничение корпуса: **у 1400 из 2100 документов пустой заголовок** (bbc-news и Georeview — только текст). Поэтому разница «с заголовком / без заголовка» (E vs E′, F vs F′) здесь работает только на трети корпуса (mlsum) — на приватном корпусе заголовки есть у всех заметок.

Потоки: torch=6, OMP_NUM_THREADS=не задан, cpu_count=12.

Артефакты с названиями заметок (не в git): `D:\knowledge-graph-ai-agents\work-model1b\local\public` — `pairs.md` (8 вариантов), `search.md` (A/E/F), `delta-sheet.md`.

Прототипы вместо промышленных модулей: нормализация — `measure_normalization.normalize_pass` (один проход + откат при результате < 100 символов), чанкер — `measure_chunking.chunk_text` (target=min(256, окно), max=окно модели). Расхождение с будущими модулями NLP-4/CHUNK-1 оговорено здесь.

Правдоподобное объяснение: публичные тексты уже чистые и однородные, нормализация/заголовок добавляют шум, а не сигнал; реальные заметки грязнее. Скорость соотношение подтвердилось: e5-base ~3× медленнее e5-small по чанку (273 vs 88 мс).
