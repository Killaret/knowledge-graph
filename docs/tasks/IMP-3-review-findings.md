## Ghost-форма: измерение, а не впечатление

Тест-стек с `ai-agents` `9f6b77b`, окно 1280 × 720, главная страница, клавиша `N`.

Дерево доступности показывает **восемь** кнопок типов. В DOM их **одиннадцать** — все отрисованы:

```
form:   x=461 y=121 w=420 h=1024      viewport h=720
galaxy    y=317  visible
nebula    y=372  visible
blackhole y=426  visible
star      y=479  visible
planet    y=535  visible
moon      y=589  visible
comet     y=643  visible
satellite y=698  bottom 742 > 720  -> not visible
asteroid  y=752                    -> not visible
dust      y=806                    -> not visible
debris    y=861                    -> not visible
```

Форма высотой 1024 px в окне 720 px. Типы идут в столбик, по 44 px плюс отступ — одни
только типы занимают ~600 px. Прокрутил вниз на десять делений и измерил снова:

```
debris  y=861  bottom 905          (не сдвинулся)
pageScrollY: 0        docScrollable: false
form: overflow-y: visible, max-height: none, position: static
единственный прокручиваемый предок: app-main, scrollHeight 720 = clientHeight 720
```

Ни страница, ни форма, ни один предок не прокручиваются. **Четыре типа недостижимы**: не
«плохо видны», а физически вне досягаемости клика при 720 px высоты. При 1080 px форма
(121 + 1024 = 1145 px) тоже не влезает — `debris` за кромкой и на Full HD.

Это ровно жалоба владельца из постановки, и ровно та причина, которую постановка назвала
первой («`.ghost-note-form` … `TypeSelector` может обрезаться»). Средства там же:
`max-height` + `overflow-y: auto` на списке типов, либо компактный выпадающий список, либо
сетка вместо столбика.

## Тесты (§4 постановки)

Не написан ни один из трёх: на число `UI_TYPES` (есть старый на состав, без `technical`),
на присутствие всех `data-type` в ghost-форме, на подсказку у каждой опции импорта.
Мутировать нечего — это само по себе вердикт: под нормой «Finishing Functionality» работа
без теста, который падает на её откате, не закончена.

## Что нужно, чтобы принять

1. Ghost-форма: список типов прокручивается или умещается — **проверять измерением** высоты
   формы против `innerHeight` в тесте, а не глазами; критерий — `debris` кликабелен при 720 px.
2. Импорт: `title` с описанием и примером на каждой `<option>` — самый дешёвый из вариантов
   постановки; или `TypeSelector`, если влезает в таблицу.
3. Три теста из §4, и мутация: убрать `overflow-y` → тест на достижимость `debris` краснеет.

## Принято без замечаний

- Набор типов в ghost-форме и в модалке создания берётся из одного источника — по коду
  `modals.svelte:72` и `CreateNoteModal.svelte:133`. Живьём модалку не сравнивал: панели
  кокпита прячут кнопку создания, а обрезание — свойство самой ghost-формы.
- `TypeSelector` у видимых восьми показывает всё, что просила постановка: emoji, название,
  описание с примером в подсказке.
