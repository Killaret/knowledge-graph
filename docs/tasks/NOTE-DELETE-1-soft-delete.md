# NOTE-DELETE-1. Мягкое удаление заметок

Статус: **бэклог — Devin, в составе 1.0, в начале очереди.** Постановка — Claude Code, 2026-09-26.

**Решение владельца (2026-09-26, NOTE-DELETE-1):** мягкое удаление чинится в 1.0. Удалённая заметка
попадает в корзину, «Восстановить» её возвращает, окончательная чистка — через 90 дней.

## Что сейчас

- `NoteModel.DeletedAt` объявлен как `*time.Time`, а не `gorm.DeletedAt`
  (`backend/internal/infrastructure/db/postgres/note_model.go:23`). Поэтому `NoteRepository.Delete`
  (`note_repo.go:112`) и `DeleteBatch` делают жёсткий `DELETE`.
- `Restore` (`note_repo.go:135`) ищет строку, которой уже нет.
- **Живьём на тест-стенде, 2026-09-26:** `DELETE /notes/:id` — 204, `POST /notes/:id/restore` — **404
  «Note not found»**, строк в `notes` — **0**. Кнопка «Восстановить» во всплывающем уведомлении
  главной заметку не возвращает.
- ADR 004 обещает мягкое удаление. Связи удаляются мягко уже сейчас — разбор DOC-AUDIT-2, строка A-26.

## Что сделать

1. **Заметки удаляются мягко.** Одиночное и пакетное удаление ставят `deleted_at`, строка остаётся.
2. **Удалённые заметки нигде не видны:** список, поиск, граф, рекомендации, ключевые слова, векторы,
   экспорт. Каждый путь чтения — с тестом.
3. **Восстановление** возвращает заметку вместе со связями, которые удалились вместе с ней. Связи,
   удалённые раньше и отдельно, не воскресают — нужен признак, по которому их различить.
4. **Окончательная чистка** — через 90 дней: уборку с таким сроком DOC-AUDIT-2 уже нашла в
   конфигурации (A-25). Проверить, что уборка берёт заметки, и описать срок в
   `CONFIGURATION_EN.md` и `CONFIGURATION_RU.md`.
5. **Граф:** после удаления узел пропадает, после восстановления возвращается без перезагрузки —
   события через механизм этапа A2 SYNC-1.
6. **Обещание** в каталоге PROMISES-1: «удалённую заметку можно восстановить в течение 90 дней».

## Критерии приёмки

1. Тест: удалить → восстановить → заметка и её связи вернулись байт в байт. Мутация «жёсткое удаление»
   — красная.
2. Тест на каждый путь чтения: удалённой заметки там нет.
3. Тест уборки с фиксированными часами: через 89 дней строка есть, через 91 — нет.
4. Живьём на стенде: удалить → «Восстановить» во всплывающем уведомлении → заметка снова в списке и
   на графе. Свидетельство — в `docs/agents/MANUAL_TEST_FEEDBACK.md`.
5. ADR 004 и `ARCHITECTURE_SUMMARY.md` описывают то, что сделано.
