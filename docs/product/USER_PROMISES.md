# USER_PROMISES — каталог обещаний пользователю (PROMISES-1)

Каждое обещание — проверяемое: условие, действие, ожидаемое, срок и тест, который его держит.
Состав утверждает владелец; сторож `scripts/testing/check-promises.mjs` падает, если у обещания
нет теста или тест пропал из кода.

Сквозные тесты несут тег `@promise` и живут в `frontend/tests/promises.spec.ts`
(self-seeding через API, проект `chromium-skip-auth` — идут в CI на PR). Обещание может
ссылаться и на существующие спеки, если те держат обещание целиком.

| № | Обещание | Условие → действие → ожидаемое | Срок | Тест |
|---|----------|------------------------------|------|------|
| P-01 | Заметка, созданная вручную, появляется в списке и на графе | Создать заметку → она в `GET /notes` и в `graph-service /v1/graph/full` | ≤ 5 с после сохранения | `promises.spec.ts` · `P-01` |
| P-02 | Импортированная закладка появляется на графе с названием страницы | Импорт `bookmarks` → заметка с заголовком страницы видна на графе | ≤ 30 с | `mass-import.spec.ts` · `previews and imports a batch of URLs` |
| P-03 | Автосвязи к новой заметке появляются на открытом графе без перезагрузки | Создать заметку → автосвязи видны в графе (SSE-дельта, SYNC-1) | ≤ 60 с (NLP-конвейер) | `promises.spec.ts` · `P-03` |
| P-04 | Переименование видно на графе без перезагрузки | `PUT /notes/:id` новый заголовок → узел графа несёт его | ≤ 5 с (после инвалидации кэша) | `promises.spec.ts` · `P-04` |
| P-05 | Удалённая заметка и удалённая связь исчезают с графа | `DELETE /notes/:id` → узел уходит из `graph/full`; то же для связи | ≤ 5 с | `promises.spec.ts` · `P-05` |
| P-06 | Заметки доступны — список и поиск — до загрузки графа | Открыть приложение с недоступным graph-service → список заметок открывается | сразу | `promises.spec.ts` · `P-06` |
| P-07 | Поиск находит заметку по слову из названия и из текста | `GET /notes/search?q=` слово из title и слово из content → заметка найдена | ≤ 2 с | `promises.spec.ts` · `P-07` |
| P-08 | Ручная связь поверх автосвязи сохраняет происхождение | `POST /links` по паре с автосвязью → связь повышена, `gamma_origin` записан | ≤ 5 с | `promises.spec.ts` · `P-08` |
| P-09 | Бэкап и восстановление возвращают все заметки и связи | Бэкап → восстановление на чистой базе → все заметки и связи на месте | регрессионный цикл | вне PR-CI: `BACKUP_ENABLED=false` на тест-стенде; ручной прогон RELEASE-TEST-1 |
| P-10 | Выключенная функция ничего не пишет | `nlp.quality.enabled=false` → quality-артефакты не создаются | на каждом сохранении | `promises.spec.ts` · `P-10` |
| P-11 | Удалённую заметку можно восстановить в течение 90 дней | `DELETE` → `POST /notes/:id/restore` → заметка возвращается в список и на граф | ≤ 5 с | `promises.spec.ts` · `P-11` |

## Решения и остаток

- **P-09 не в PR-CI**: на тест-стенде бэкап выключен по дизайну; обещание проверяется в
  регрессионном цикле и ручном прогоне RELEASE-TEST-1. Перенос в CI — решение владельца.
- **P-03** проверяется опросом `graph/full` до появления связи (SSE проверен юнит-тестами
  `sse_test.go`); UI-уровень без перезагрузки покрыт SSE-клиентом — отдельный браузерный тест
  с реальным воркером слишком хрупок для PR-прогона.
- Мутационные проверки (критерий 2) записаны в
  [`tasks/PROMISES-1-user-promises.md`](../tasks/PROMISES-1-user-promises.md).
