# Типы связей в Knowledge Graph

**Обновлено:** сентябрь 2026 (LINK-TYPES-1)

## Обзор

Типы связей определяют характер отношений между заметками в графе знаний. Правильный выбор типа помогает структурировать знания, улучшает навигацию и делает граф визуально осмысленным.

Типы, видимые пользователю:

| Тип | Иконка | Вес по умолчанию | Стиль линии | Цвет |
|------|--------|------------------|-------------|------|
| Зависимость | 🔗 | 0,7 | пунктир `[10, 3]` | `#ff6600` |
| Связано | 🔀 | 0,5 | сплошная, при весе < 0,3 → пунктир `[6, 4]` | `#999999` |
| Родитель | ⬆️ | 0,9 | сплошная | `#2dd4bf` |
| Дочерняя | ⬇️ | 0,9 | сплошная | `#f472b6` |
| Автосвязь (модель) | ✨ | — | тонкая сплошная | `#4ade80` |

> **Устаревшие типы.** `reference` и `custom` объявлены устаревшими (LINK-TYPES-1).
> API их по-прежнему принимает, но сохраняет как `related`; миграция 037
> переписала существующие строки и слила дубликаты пар (выживает одна связь с
> максимальным весом, поглощённые удаляются мягко). Из выбора, фильтров и
> легенды оба типа убраны. `parent`/`child` остаются системными связями
> происхождения до ORIGIN-1.

## Доступные типы

### Связано — тип по умолчанию

- **Иконка:** 🔀
- **Смысл:** Заметки тематически связаны, но ни одна не зависит от другой. Тип по умолчанию везде: колонка в базе, API при отсутствии типа и форма создания.
- **Когда использовать:** Близкие темы, альтернативные подходы, «см. также» — всё, что раньше было `reference`/`custom`.
- **Пример:** «JavaScript» → Связано → «TypeScript».
- **Визуал:** Серая сплошная линия; становится пунктирной, если вес ниже 0,3.

### Зависимость — направленная цепочка

- **Иконка:** 🔗
- **Смысл:** A→B означает, что A — предусловие, а B идёт следом: направление «от того, что делается сначала, к тому, что потом».
- **Когда использовать:** Цепочки задач, предусловия, упорядоченные шаги, учебные траектории.
- **Пример:** «Docker Basics» → Зависимость → «Docker Compose».
- **Визуал:** Оранжевая пунктирная линия; анимация пунктира бежит по направлению связи, как огни на взлётной полосе.
- **Подсветка цепочки (2D и 3D):** наведение на заметку с зависимостями подсвечивает всю цепочку через неё — и предусловия, и зависимые — и гасит остальное. Яркость спадает с расстоянием от заметки под курсором; обход ограничен `frontend.graph.dependency_highlight_depth` (по умолчанию 10). При переходе курсора на другую заметку цепочки подсветка пересчитывается от неё.
- **Циклы:** связи, лежащие на цикле зависимостей, рисуются красным, а панель заметки показывает предупреждение и строки **«Требует:»** (входящие зависимости) и **«Нужна для:»** (исходящие).

### Родитель / Дочерняя

- **Иконки:** ⬆️ / ⬇️
- **Смысл:** связи происхождения — исходная заметка более широкая тема / подтема. Управляются системой; перенос в отдельную концепцию запланирован в ORIGIN-1.
- **Визуал:** Бирюзовая / розовая сплошные линии.

### Автосвязь (модель)

- **Иконка:** ✨
- **Смысл:** `source_type = "gamma"` — связь, предложенная моделью сходства, а не ручной тип. В легенде — отдельная строка; через фильтр типов не переключается.
- **Визуал:** Зелёная (`#4ade80`) — оттенок, которого нет ни у одного ручного типа — тоньше и прозрачнее ручных связей; яркость следует за весом сходства. Подтверждение связи в тултипе повышает её до `source_type = "user"`, и она принимает цвет своего типа.

## Выбор типа

```
Является ли одна заметка предусловием для другой?
  Да → Зависимость
  Нет →
    Является ли одна заметка более / менее широкой темой?
      Да → Родитель / Дочерняя (управляются системой)
      Нет → Связано
```

## Визуальное кодирование

- **Цвет** — ручные связи берут `LinkType.color`; автосвязи — `AUTO_LINK_COLOR` (`#4ade80`).
- **Пунктир** берётся из `LinkType.lineDash`. Тип `related` переключается на `[6, 4]`, если `weight < 0,3`; пунктир `dependency` анимируется в направлении связи.
- **Толщина линии** — `Math.max(1, weight * 4)`, ×0,55 для автосвязей и ×1,5 при предупреждении о дублирующейся связи.
- **Непрозрачность** — база `0.4 + weight * 0.4`; автосвязи дополнительно ×0,45.
- **Цепочка зависимостей:** связи цепочки гаснут с глубиной BFS (`max(0.35, 1 - depth * 0.12)`), элементы вне цепочки — до ~0,15; связи цикла — красные (`#ef4444`).
- **Двунаправленные связи** (A→B и B→A) рисуются двумя зеркальными квадратичными кривыми, чтобы не накладываться.
- **Удалённые связи** растворяются, **новые** появляются с fade-in анимацией.

## Интеграция в UI

- `LinkTypeSelector` (`frontend/src/components/molecules/LinkTypeSelector.svelte`) — выбор типа с иконкой, цветом и описанием.
- `CockpitNoteDetails` — список связей заметки с иконкой, весом, `source_type` и `last_weight_update`, плюс строки зависимостей «Требует / Нужна для» и предупреждение о цикле.
- `LinkTooltip` — тултип на графе с типом, цветом, весом, источником/целью и датой обновления. У связей с `source_type = "gamma"` — действия **«Подтвердить связь»** (строка повышается до `source_type='user'`, происхождение сохраняется в `metadata.gamma`) и **«Не связаны»** (удаление с записью отказа в `link_suppressions` — пара больше не предлагается).
- `LinkTypeLegend` — легенда на графе: ручные типы (фильтр + минимальный вес) и статичная строка «Автосвязь (модель)» — в 2D и в 3D.

## API

### Создать связь

```bash
POST /api/v1/links
{
  "source_note_id": "uuid-1",
  "target_note_id": "uuid-2",
  "link_type": "related",
  "weight": 0.8
}
```

`link_type` принимает `reference`, `dependency`, `related`, `custom`, `parent`, `child`. Устаревшие `reference`/`custom` перед сохранением нормализуются в `related` — ответ возвращает `"link_type": "related"`.

### Обновить связь

```bash
PUT /api/v1/links/:id
{
  "link_type": "dependency",
  "weight": 0.9
}
```

### Данные графа

Ответы `/api/v1/graph/public`, `/api/v1/notes/:id/graph` содержат:

```json
{
  "id": "uuid",
  "source": "uuid-1",
  "target": "uuid-2",
  "weight": 0.8,
  "link_type": "related",
  "source_type": "user",
  "last_weight_update": "2026-07-29T12:00:00Z"
}
```
