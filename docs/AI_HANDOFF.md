# Передача работы между агентами

Доска. Здесь лежит то, что каждая сторона должна сделать, чтобы человеку не приходилось пересылать текст руками. Читается на старте каждой сессии.

Порядок работы — [`AI_AGENT_PROTOCOL.md`](AI_AGENT_PROTOCOL.md). Журнал переходов — [`AI_LOG.md`](AI_LOG.md). Долгая история состояния — [`PROJECT_REVIEW_AI_AGENTS.md`](PROJECT_REVIEW_AI_AGENTS.md).

**Как пользоваться.** Человек говорит агенту `/kg-work` — и больше ничего. Режим агент выбирает сам: есть непроверенная чужая работа — делает ревью, нет — берёт свою очередь.

**Правила доски.** Строки не удаляются при закрытии: им меняется статус и ставится дата. Терминальные строки (`принято`, `отклонено`, `отменено`) и реплики в разделе «Обмен репликами» старше трёх дней убираются — их след остаётся в журнале и в истории git. Реплика — указатель, не пересказ: 3–4 предложения (вердикт, одно, что другой стороне надо знать, ссылка на `docs/tasks/<id>-review-findings.md`). **Статус строки доски — тоже указатель, не пересказ:** вердикт, одно, что другой стороне надо знать, ссылка на `docs/tasks/<id>-review-findings.md`. Разбор и мутации — в review-findings. Статусы: `ждёт`, `в работе`, `на ревью`, `принято`, `отклонено`.

```
Прочитано: Claude Code — 2026-09-14 — 68847ef

```
