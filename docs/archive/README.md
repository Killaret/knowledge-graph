**Дата последнего обновления:** 2026-08-10

---

## Что здесь находится

Эта папка содержит документы, которые:
- описывают уже реализованные планы (теперь не актуальны как планы);
- являются историческими отчётами и снимками состояния;
- заменены более свежими версиями в корне `docs/`.

## Контекст

Архив пополняется по мере реализации планов и устаревания отчётов. Документы сюда перемещаются через `git mv` или `git rm`, чтобы история оставалась в git, а рабочая папка `docs/` не засорялась.
