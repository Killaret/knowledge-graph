# Актуальный чек-лист ручного тестирования

> **Дополнение:** для ветки `ai-agents` / 3D-рефакторинга см. [MANUAL_TEST_CHECKLIST_AI_AGENTS_3D_REFACTOR.md](MANUAL_TEST_CHECKLIST_AI_AGENTS_3D_REFACTOR.md).

**Последнее обновление:** Allotropic-carbon theme (градиенты, свечение, углеродные поверхности), редизайн `Button`, `Modal`, `NoteForm`, `TypeSelector`, `NoteCard`, `BackButton`, `SearchBar`, `AuthCard`, `EditNoteModal`, `CreateNoteModal`; полная переработка страницы заметки `/notes/[id]` с метаданными, связями, похожими заметками, кнопками действий и переходами.

**Окружение**

- Frontend: `http://127.0.0.1:3002` (или `FRONTEND_PORT`, если 3002 занят Hyper-V excluded range); на Windows используйте `127.0.0.1` вместо `localhost`, чтобы избежать проблем с `::1`.
- Backend: `http://127.0.0.1:18083`
- Тестовый пользователь: `testuser` / `TestPassword123!`
- Тестовые данные: 100 notes + 60 links (по умолчанию); можно переопределить параметрами `seed-test-data.ps1`
- `hover_delay_ms` в `knowledge-graph.config.json` → `frontend.graph.2d.hover_delay_ms` = 150
- В режиме real-auth фронтенд обращается к бэкенду через same-origin прокси `/api` и `/graph-service/api`; серверный прокси (`frontend/src/hooks.server.ts`) пробрасывает заголовки `Authorization` и `Cookie`, включая HttpOnly auth cookies.
- **Для real-auth тестов стек запускается с `SKIP_AUTH=false`**, и `seed-test-data.ps1` выполняется в том же режиме; иначе заметки создадутся под анонимным владельцем и граф в real-auth режиме окажется пустым.
- `seed-test-data.ps1`/`.sh` публикуют `-PublicPercent` (по умолчанию 20%) заметок через `POST /notes/:id/publish`, чтобы публичный (анонимный) граф не был пустым в real-auth режиме.

## 3. Canvas Features

**Для создания связей используйте страницу `/graph`**, т.к. на главной (`/`) GraphCanvas не передаёт `onLinkCreate`.

### Hover / затемнение
- [ ] Быстро провести курсором над любой нодой — граф не затемняется.

- [ ] Задержать курсор на связи ~150 ms — появляется `LinkTooltip` с типом связи и весом.

### Ghost-нода
- [ ] Нажать `N` на `/graph` — открывается форма создания заметки.
- [ ] Заполнить title/content, выбрать тип, создать.

- [ ] Открыть `/graph` с ~50-100 нодами. Граф загружается без длительных фризов.

## 5. Валидация и пользовательские сообщения об ошибках

### Валидация длины заголовка заметки
- [ ] Открыть форму создания заметки (верхний бар или `N` на `/graph`).
- [ ] Ввести заголовок длиннее 200 символов.
- [ ] **Ожидаемый результат:** фронтенд блокирует отправку формы, показывает ошибку валидации.
- [ ] **Проверка:** индикатор длины показывает `200+/200` и становится красным.
- [ ] **Проверка:** кнопка "Создать" отключена при превышении лимита.
- [ ] **Проверка:** текстовое сообщение об ошибке понятно объясняет лимит (на русском/английском).
- [ ] Проверить в DevTools Network: нет запроса к API при превышении лимита (валидация на фронтенде).

### QuickCaptureWidget (пылинки)
- [ ] Нажать кнопку ✨ или `Ctrl+Shift+N`.
- [ ] Ввести очень длинный текст (>200 символов).
- [ ] **Ожидаемый результат:** заголовок автоматически обрезается до допустимой длины.
- [ ] **Проверка:** пылинка создаётся успешно без ошибки валидации.
- [ ] **Проверка:** заголовок имеет форму "первые 197 символов...".

### Сообщения об ошибках API
- [ ] Попробовать создать заметку с пустым заголовком.
- [ ] **Ожидаемый результат:** фронтенд показывает понятное сообщение об ошибке.
- [ ] **Проверка:** сообщение локализовано (русский/английский в зависимости от настроек).
- [ ] **Проверка:** в DevTools Network есть запрос к API с ошибкой 400/422.
- [ ] **Проверка:** ответ API содержит `VALIDATION_ERROR` и понятное описание поля.
- [ ] **Проверка:** компонент `ApiErrorDisplay` показывает ошибку в удобном виде.

### Ответы API при ошибках валидации
- [ ] Создать заметку с некорректными данными (пустой заголовок).
- [ ] **Проверка:** API возвращает JSON с полями:
  - `code: "VALIDATION_ERROR"`
  - `message: "Invalid input data"`
  - `details: [{ field: "title", reason: "invalid_value", message: "..." }]`
- [ ] **Проверка:** HTTP статус код 422 Unprocessable Entity.
- [ ] **Проверка:** CORS заголовки присутствуют в ответе об ошибке.

### Валидация на бэкенде (fallback)
- [ ] Отключить фронтенд-валидацию (через DevTools или модификацию JS).
- [ ] Попробовать отправить заголовок длиннее 200 символов напрямую через API.
- [ ] **Ожидаемый результат:** бэкенд возвращает ошибку валидации.
- [ ] **Проверка:** ответ API содержит ошибку с полем `title` и ограничением `max`.
- [ ] **Проверка:** сообщение об ошибке понятно описывает лимит (200 символов).

### Пользовательский опыт при ошибках
- [ ] При ошибке валидации форма не закрывается, данные сохраняются.
- [ ] Пользователь может исправить ошибку и повторить отправку.
- [ ] Кнопка закрытия ошибки (`×`) скрывает сообщение.
- [ ] После исправления ошибки сообщение исчезает автоматически.

## Известные ограничения в текущей сборке

- **Чёрная дыра:** glow на hover есть, но удаление ноды перетаскиванием в чёрную дыру не реализовано.
- **Перемещение нод:** drag используется для создания связей; свободное перемещение нод по canvas не поддерживается.
- **Ctrl+Z:** placeholder — undo в canvas не реализован.
- **Создание связей на главной (`/`):** GraphCanvas на `/` не получает `onLinkCreate`, поэтому форма связи откроется, но callback не сработает. Для создания связей используйте `/graph`.
- **Real-auth smoke:** до входа в Network может быть один `400` на `/api/v1/auth/refresh` (нет refresh cookie) — ожидаемо. После входа граф может запросить `/api/v1/notes/00000000-0000-0000-0000-000000000001` и получить `404` (default Knowledge Core-нода отсутствует в notes) — не блокирует тестирование.
- **Переход login → `/`:** в момент анимации страницы в DOM может ненадолго появиться два `data-testid="graph-stats"` (фоновый граф `AuthCard` + главный граф); Playwright-тесты используют `.first()`.
