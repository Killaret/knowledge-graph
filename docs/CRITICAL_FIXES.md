# Оперативные исправления и дополнения

**Создано:** 29 июля 2026 г.  
**Статус:** 🔄 В процессе

## Обзор

Документ содержит оперативные исправления, найденные в процессе тестирования и разработки, а также задачи по дополнению функционала.

## 🚨 Критические исправления

### 1. Исправление дефолтного типа заметки

**Проблема:** Если тип заметки не указан, система дефолтила в "star", что неверно.

**Исправление:** Изменить дефолтный тип на "unknown" для неизвестных типов.

**Файлы:**
- `backend/internal/domain/note/entity.go` — NewNote, NewNoteWithCreator, ReconstructNote, ReconstructNoteWithCreator
- `backend/internal/infrastructure/db/postgres/note_repo.go` — toGormNote, toDomainNote

**Статус:** ✅ Исправлено

---

### 2. Синхронизация типов заметок между frontend и backend

**Проблема:** Валидация типов заметок на backend не содержала все типы из frontend доменной модели.

**Исправление:** Синхронизировать валидацию со всеми типами из CelestialBody.

**Файлы:**
- `backend/internal/interfaces/api/notehandler/note_handler.go` — createNoteRequest, updateNoteRequest
- `backend/internal/interfaces/api/common/validation/validators.go` — ValidCelestialBodyTypes

**Статус:** ✅ Исправлено

---

### 3. Исправление валидации PUT запросов заметок

**Проблема:** PUT запросы для обновления заметок возвращали 400 Bad Request из-за отсутствия типа "satellite" в валидации.

**Исправление:** Добавить все поддерживаемые типы в валидацию updateNoteRequest.

**Файлы:**
- `backend/internal/interfaces/api/notehandler/note_handler.go` — updateNoteRequest

**Статус:** ✅ Исправлено

---

### 4. Улучшение tooltip для карточек заметок

**Проблема:** При наведении на заметку показывался обрезанный заголовок без возможности увидеть полный контент.

**Исправление:** Показывать полный заголовок, превью контента, дату и больше ключевых слов.

**Файлы:**
- `frontend/src/components/molecules/NoteCard.svelte` — buildTooltipContent, стили

**Статус:** ✅ Исправлено

---

### 5. Документация типов связей

**Проблема:** Пользователи не понимали что такое "тип связи" и какие типы существуют.

**Исправление:** Создать полную документацию по типам связей с примерами и визуализацией.

**Файлы:**
- `docs/LINK_TYPES.md` — новая документация

**Статус:** ✅ Создано
