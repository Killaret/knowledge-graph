- [ ] Сохранить → заметка создается
- [ ] Заметка появляется на графе
- [ ] API запрос: POST /api/v1/notes

### ✅ Редактирование заметки
- [ ] Кликнуть на заметку в графе
- [ ] Нажать "Edit" → открывается модальное окно
- [ ] Изменить title/content
- [ ] Сохранить → изменения применяются
- [ ] API запрос: PUT /api/v1/notes/{id}

### ✅ Удаление заметки

- [ ] Нажать "Delete" → появляется подтверждение
- [ ] Подтвердить → заметка удаляется
