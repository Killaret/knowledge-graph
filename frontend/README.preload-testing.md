# Тестирование PreloadService

## Обзор тестового покрытия

Реализовано комплексное тестирование системы предзагрузки данных:

### Unit тесты
- **PreloadService.test.ts** - тестирование основного сервиса
- **usePreloadedData.test.ts** - тестирование хуков для использования данных

### Интеграционные тесты
- **auth.svelte.test.ts** - тестирование интеграции с системой аутентификации

### E2E тесты
- **preload-full-cycle.spec.ts** - тестирование полного пользовательского цикла

## Запуск тестов

### Unit тесты
```bash
# Запуск всех unit тестов PreloadService
npm run test:preload

# Запуск с покрытием
npm run test:preload:coverage

# Запуск конкретного файла
npm run test:preload -- src/lib/services/PreloadService.test.ts
```

### E2E тесты
```bash
# Запуск E2E тестов предзагрузки
npm run test:e2e:preload

# Запуск с графическим интерфейсом
npm run test:e2e:preload:ui
```

## Структура тестов

### 1. Unit тесты PreloadService

Покрывают:
- Singleton паттерн
- Запуск предзагрузки в различных условиях
- TTL кэширование
- Управление кэшем
- Обработку ошибок
- Параллельные операции
- Статистику и мониторинг

### 2. Unit тесты хуков usePreloadedData

Покрывают:
- Умный выбор источника данных (кэш vs сервер)
- Мгновенное отображение
- Комбинированную загрузку
- Обработку ошибок
- Логирование

### 3. Интеграционные тесты с authStore

Проверяют:
- Очистку кэша при выходе
- Сохранение кэша при входе
- Обработку ошибок аутентификации
- Разные окружения (browser/server)

### 4. E2E тесты

Тестируют полный цикл:
- Предзагрузка на странице входа
- Мгновенное отображение после входа
- Обработка ошибок сети
- Очистка кэша при выходе
- Работа с разными ролями пользователей
- Параллельные сессии
- Истечение TTL

## Best Practices тестирования

### 1. Изоляция тестов
- Каждый тест независим
- Очистка состояния в beforeEach/afterEach
- Моки вместо реальных API

### 2. Комплексное покрытие
- Unit тесты для отдельных функций
- Интеграционные тесты для взаимодействия модулей
- E2E тесты для пользовательских сценариев

### 3. Обработка ошибок
- Тестирование сетевых ошибок
- Проверка graceful degradation
- Валидация fallback механизмов

### 4. Производительность
- Измерение времени загрузки
- Проверка параллельных операций
- Тестирование TTL механизма

## Отладка тестов

### Логирование
Тесты используют детальное логирование для отладки:
```
[PreloadService] Starting background preload...
[usePreloadedData] Using preloaded graph data
```

### Инструменты
- **vitest --ui** - графический интерфейс для отладки
- **playwright --debug** - пошаговая отладка E2E тестов
- **console.log** в тестах для временной отладки
