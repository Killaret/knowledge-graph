# /kg-handoff — выполнить задания Devin из инбокса

Активируется, когда пользователь пишет `/kg-handoff`. Человеку не нужно пересылать текст из инбокса — вся постановка и замечания живут в `docs/AI_HANDOFF.md` и `docs/tasks/`.

## Порядок работы

1. Прочитать `.windsurfrules`.
2. Прочитать `.devin/skills/knowledge-graph/SKILL.md` — базовый workflow Devin.
3. Прочитать `docs/AI_HANDOFF.md`.
4. Найти в разделе **На Devin** задачи, которые ещё не выполнены.
5. Для каждой задачи:
   - прочитать связанный `docs/tasks/<id>.md`;
   - пропустить, если условие ещё не наступило (например, «после A-3»);
   - выполнить задачу, сохранив малый охват и не трогая стеки/данные, не относящиеся к задаче;
   - не запускать Personal-стек без явной просьбы;
6. После выполнения обновить `docs/AI_HANDOFF.md`:
   - перенести сделанные задачи в **Сделано**;
   - дописать **Обмен репликами** — коротко, что было сделано и что ждёт ревью/решения человека.
7. Если нужна передача Claude Code, обновить `docs/AI_HANDOFF.md` и не пытаться выполнять задачи раздела **На Claude Code**.

## Чего не делать

- Не трогать задачи из разделов **На Claude Code** и **На человеке**.
- Не запускать Personal-стек.
- Не удалять данные Personal-стека без бэкапа.
- Не коммитить без явной просьбы.
