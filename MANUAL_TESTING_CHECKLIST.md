## 🚀 1. Проверка PreloadService

### 1.1 Холодная загрузка (Cold Start)
- [ ] Открыть приложение в инкогнито режиме
- [ ] Проверить консоль: должно быть сообщение `[PreloadService] Starting preload`
- [ ] В Network вкладке увидеть запросы к API:
  - `GET /api/v1/graph/all` — публичный граф
  - `GET /api/v1/users/achievements` — публичные достижения
- [ ] Убедиться, что запросы выполняются параллельно
- [ ] Проверить TTL кэширования (5 мин для графа, 10 мин для достижений)

### 1.2 Предзагруженные данные (Cached Data)
- [ ] Войти в приложение
- [ ] Убедиться, что при входе сначала отображаются предзагруженные данные из кеша
- [ ] В Network вкладке увидеть `GET /api/v1/me/graph/cached` и затем `GET /api/v1/me/graph/fresh`
- [ ] Обновить страницу (F5)
- [ ] Проверить консоль: должно быть сообщение `[PreloadService] Using cached data` или `[+page] Using preloaded graph data for instant display`
- [ ] Проверить, что обновление выполняется без полной перерисовки графа (дельта применяется инкрементально)

### 1.3 Очистка кэша
- [ ] Выйти из приложения
- [ ] Проверить консоль: должно быть сообщение `[PreloadService] Cache cleared`
- [ ] Обновить страницу
- [ ] Убедиться, что запросы к API выполняются снова

## 🌫 2. Проверка эффекта "Завесы Тумана"

### 2.1 Начальный туман
- [ ] Перейти на страницу с 3D-графом
- [ ] Убедиться, что туман появляется с плотностью 0.08
- [ ] Проверить консоль: `[Graph3D] Starting simulation with preloaded data: false, initial fog density: 0.08`
- [ ] Визуально проверить, что туман плотный и скрывает дальние узлы

### 2.2 Прогрессивное рассеивание
- [ ] Наблюдать за рассеиванием тумана по мере позиционирования узлов
- [ ] Проверить консольные логи прогресса: `[Graph3D] Fog progress: X.X%, density: X.XXXX`
- [ ] Убедиться, что туман становится менее плотным постепенно
- [ ] Проверить, что обновление происходит каждые 5 тиков симуляции

### 2.3 Финальная анимация
- [ ] Дождаться завершения симуляции
- [ ] Проверить, что запускается плавная анимация до плотности 0.005
- [ ] Убедиться, что финальная плотность почти прозрачная
- [ ] Проверить, что все узлы становятся хорошо видимы

### 2.4 Интеграция с PreloadService
- [ ] Выйти и войти снова с предзагруженными данными
- [ ] Проверить консоль: `[Graph3D] Starting simulation with preloaded data: true, initial fog density: 0.04`
- [ ] Убедиться, что начальный туман менее плотный (0.04)
- [ ] Проверить, что эффект все равно работает корректно

### 2.5 Edge Cases
- [ ] Проверить с пустым графом (0 узлов)
- [ ] Проверить с графом из 1 узла
- [ ] Проверить с большим графом (>100 узлов)
- [ ] Проверить с графом без связей
- [ ] Убедиться, что в этих случаях туман сразу устанавливается на 0.005
