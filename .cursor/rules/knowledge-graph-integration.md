# Cursor Rule: knowledge-graph-integration

Agent Integration отвечает за:
- API mapping и OpenAPI
- Протоколы, вебхуки, OAuth и интеграционные контракты
- Генерацию DTO и проверку соответствия спецификациям

Команды:
- «Создай OpenAPI схему для нового endpoint»
- «Напиши webhook-получатель»
- «Проверь контракты API»
